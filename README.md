# HZ-BIM

AI coordination for **Autodesk Revit (2020–2027)** and **Navisworks Manage (2020–2027)**, connected to Claude Desktop through MCP.

## Install

1. Download **`HZ-BIM-Setup.exe`** from [Releases](https://github.com/hazzem0/HZ-BIM-Releases/releases/latest).
2. Run it, pick your Revit / Navisworks versions, finish.
3. Open Revit → **HZ-BIM** tab → **License** (or Navisworks → **Add-ins → HZ-BIM License**).
4. Send the **Machine ID** shown there to Hazem Ahmed Ali and paste the key you receive.

A license key works on one computer. Trial keys stop on their end date.

## Uninstall

Windows Settings → Apps → **HZ-BIM** → Uninstall.
